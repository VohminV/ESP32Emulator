# ESP32Emulator

Эмулятор микроконтроллера ESP32 с визуальным интерфейсом на Qt.
Проект позволяет запускать базовую эмуляцию работы ESP32 и видеть лог выполнения без физического устройства.

---

## 🔹 Текущее состояние (MVP)

- GUI на Qt с основными компонентами:
  - **Меню и панель инструментов** с кнопками `Start`, `Stop`, `Step`
  - **Центральная область** с вкладками (`Schematic` и другие)
  - **Док-виджет снизу**: `Protocol Log` (QTextEdit) для отображения логов
  - **Док-виджет справа**: `Registers & Memory` (QTreeWidget) для инспекции состояния
- **Минимальное ядро эмулятора** (`EmulatorCore`) на C++:
  - Методы `start()`, `stop()`, `step()`
  - Логирование действий в GUI через `Protocol Log`
  - Подключение таймера для шаговой эмуляции (`QTimer`)

> MVP позволяет запускать/останавливать эмуляцию и видеть события в логах.

## 🔹 Быстрый старт

1. Установите [Qt 6.x](https://www.qt.io/download) с компонентами MinGW 64-bit и Qt Creator.
2. Откройте `ESP32Emulator.pro` в Qt Creator.
3. Соберите и запустите проект.
4. Используйте кнопки `Start`, `Stop` и `Step` для управления эмуляцией.
